## Fresh-clone Quick Start acceptance

The public GitHub tag was cloned into a separate clean directory. The checkout resolved to the source revision above. Dependencies were installed with lifecycle scripts disabled, and the repository was built before running the documented product-shot journey:

```text
voce pack validate --source fixtures/packs/product-shot --json
voce case compile --case fixtures/cases/product-shot.json --scenario fixtures/packs/product-shot --profile fixtures/profiles/mock-image.json --out .local-output/product-shot-compiled --json
voce case run --bundle .local-output/product-shot-compiled --provider mock --out .local-output/product-shot-run --json
voce trace render --bundle .local-output/product-shot-run --out .local-output/product-shot.html --json
```

## Trace safety review

The generated dependency-free HTML contained the expected title and the Timeline, Budgets and destinations, Receipts and cleanup, Evaluation, and Warnings sections. Static checks found:

- no script elements;
- no external HTTP references;
- no bearer credentials; and
- no local user path disclosure.

The automated in-app browser did not open the local `file://` report because that browser surface blocks local-file navigation. The report was therefore structurally and safety validated, but this run does not claim automated visual browser inspection.
