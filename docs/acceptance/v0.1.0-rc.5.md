# v0.1.0-rc.5 Playground package acceptance

Status: release-candidate verification in progress on 2026-08-21. This report covers deterministic packaging and clean installation. It does not claim production readiness, public deployment, or real-Provider quality.

## Release scope

RC.5 keeps the four existing public packages and adds the local Playground as a separate fifth package:

| Package | Version | RC.5 purpose |
|---|---:|---|
| `@voce-engine/contracts` | `0.1.0-rc.5` | Public contracts and schemas |
| `@voce-engine/core` | `0.1.0-rc.5` | Deterministic ontology, planning, prompt, and evaluation runtime |
| `@voce-engine/testkit` | `0.1.0-rc.5` | Offline fixtures and Mock helpers |
| `@voce-engine/cli` | `0.1.0-rc.5` | Offline command-line workflows |
| `@voce-engine/playground` | `0.1.0-rc.5` | Installable local web Host for Virtual Try-On and Cosplay |

The Playground package contains public declarations, the `voce-playground` executable, its English Browser UI, the environment-variable name example, and all 30 Cosplay composition example images. It contains no API keys, uploaded user images, generated outputs, temporary URLs, or public-deployment configuration.

## Required deterministic evidence

Before publication, the exact tagged revision must pass:

- repository validation and all offline tests;
- candidate compatibility and security gates;
- two independent package builds with identical audited tarball content;
- a five-package local-tarball consumer with lifecycle scripts disabled and no workspace fallback;
- installed Playground import, local server start, `/playground`, `/api/meta`, `/api/composition-presets`, and a packaged composition JPEG;
- clean-room installation, release-candidate manifest generation, checksum verification, and intentional checksum-tamper rejection.

The installed Playground acceptance enables no real transport and makes zero Provider calls. Previous local product testing and RC.4 real-Provider composition evidence remain qualitative context rather than an RC.5 automatic gate.
