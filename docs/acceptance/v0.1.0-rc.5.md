## Release scope

RC.5 keeps the four existing public packages and adds the local Playground as a separate fifth package:

| Package | Version | RC.5 purpose |
|---|---:|---|
| `@voce-engine/contracts` | `0.1.0-rc.5` | Public contracts and schemas |
| `@voce-engine/core` | `0.1.0-rc.5` | Deterministic ontology, planning, prompt, and evaluation runtime |
| `@voce-engine/testkit` | `0.1.0-rc.5` | Offline fixtures and Mock helpers |
| `@voce-engine/cli` | `0.1.0-rc.5` | Offline command-line workflows |
| `@voce-engine/playground` | `0.1.0-rc.5` | Installable local web Host for Virtual Try-On and Cosplay |

The Playground package contains public declarations, the `voce-playground` executable, its English Browser UI, the environment-variable name example, and all 30 Cosplay composition example images. It contains no API keys, uploaded user images, generated outputs, temporary URLs, or public-deployment configuration.
