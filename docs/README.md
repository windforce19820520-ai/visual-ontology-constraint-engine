English is the normative language for public contracts and architecture decisions. Complete Chinese translations are maintained for the four-document paired core specification set—scenario design, system design, glossary, and the ScenarioPack contract—and each translation links back to its normative English source.

## Translation policy

- Public type names, schema fields, package names, event names, and error codes remain English in every language.
- English is authoritative when translations differ.
- A material change to a paired core specification is incomplete until its Chinese document is updated in the same pull request.
- Translations preserve decisions and examples, but do not need to mirror sentence structure.
- Stable scenario IDs, requirement IDs, enums, code identifiers, and Mermaid topology must match across paired design documents.
