## 翻译规则

- 公共类型、Schema 字段、包名、事件名和错误码在所有语言中统一使用英文。
- 双语内容发生差异时，以英文版本为准。
- 成对核心规范的重大修改必须在同一个 PR 中同步更新中文版本。
- 翻译必须保留决策、约束和示例，不要求逐句对应。
- 稳定场景 ID、系统要求 ID、枚举、代码标识符和 Mermaid 拓扑必须在两种语言中保持一致。
