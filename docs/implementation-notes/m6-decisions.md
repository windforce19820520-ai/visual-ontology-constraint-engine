# M6 implementation decisions

- M6 adds provider-neutral transport envelopes and keeps credential values host-only. The default transport is disabled/offline; `RecordingMockTransport` is the only standard test transport and every adapter dispatch verifies the supplied `RemoteCallAuthorization` against adapter/profile, model, destination/region, data categories, artifact hashes, input hash, and call/timeout/cost/byte limits.
- Seedream request construction is deliberately narrow: the native `image` field is the only reference field, cardinality is fixed to one output, and unsupported `images`, `image_urls`, sequential-generation, and product-specific background fields fail before transport.
- The earlier concrete background-removal adapter was removed during the v0.1 scope cleanup. Background removal and stage compositing belong to host products; VOCE keeps only provider-neutral optional postprocessing contracts.
- Structural validation reads only reproducible byte fixtures or host-supplied bytes. It proves signatures, basic dimensions, Alpha metadata, media type, byte limits, cardinality, and artifact availability; visual background transparency and semantic fidelity remain `unknown`/review findings.
- Semantic review is a separate, authorized proposal path. Fixture findings carry model/adapter/profile and evidence identifiers, but cannot mutate ontology, constraints, bindings, execution state, or human acceptance. Human decline is therefore retained as a review decision while technical outcome remains unchanged.
- `EvaluationReport` is a new layered projection compatible with the M5 `Evaluation` and `HumanAcceptance` records. Comparison ignores volatile timestamps and run identifiers but retains semantic hashes, versions, adapter/profile, budgets, destinations, and finding changes. Static HTML is deterministic, escaped, redacted, dependency-free, and never opens a browser.
- Provider response URLs and base64 are transient adapter inputs only. Successful persistence returns a safe `ArtifactHandle`; an unsaved URL or invalid output is an explicit persistence/validation failure. No production endpoint or request field is inferred beyond the generic envelope, and real smoke confirmation remains deferred.
- The repair closes the provider binding over purpose, adapter digest, profile ID/digest, optional model ID/version, artifact hashes, data categories, budgets, and idempotency identity. A lookup is constructed from the original request and the offline recording transport bounds send and lookup consumption separately; lookup never resubmits.
- Hash projections replace sensitive values with typed content digests rather than one shared redaction token. Public adapter results carry only a body-free response receipt, while raw provider bodies remain transient until persistence succeeds.
- Seedream ArtifactHandles must resolve to bytes whose content hash and declared media type match the detected signature; native image values are URL/data URI or correctly typed data URIs. Endpoint profiles are checked against their configured host suffix, and undeclared output formats fail before transport.
- Structural transparent checks report Alpha-channel presence separately from visual transparency. Semantic execution validates returned report, finding, confidence, and evidence bindings and maps failed/unknown proposals to matching receipt/run states. Comparison preserves order for plan/prompt sequences, and trace model construction validates nested hashes before public redaction.
