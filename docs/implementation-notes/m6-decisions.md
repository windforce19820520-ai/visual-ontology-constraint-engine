# M6 implementation decisions

- M6 adds provider-neutral transport envelopes and keeps credential values host-only. The default transport is disabled/offline; `RecordingMockTransport` is the only standard test transport and every adapter dispatch verifies the supplied `RemoteCallAuthorization` against adapter/profile, model, destination/region, data categories, artifact hashes, input hash, and call/timeout/cost/byte limits.
- Seedream request construction is deliberately narrow: the native `image` field is the only reference field, cardinality is fixed to one output, and unsupported `images`, `image_urls`, and sequential-generation fields fail before transport. Transparent output is accepted only for one supplied Alpha PNG reference and PNG output; this is a structural input guard, not a visual-quality claim.
- veImageX background removal uses a versioned generic provider envelope because production field names are not stable in the public design. The adapter requires a safe artifact handle and injected resolver/sink, treats processing or uncertain responses as `submission_unknown`, and never resubmits during lookup.
- Structural validation reads only reproducible byte fixtures or host-supplied bytes. It proves signatures, basic dimensions, Alpha metadata, media type, byte limits, cardinality, and artifact availability; visual background transparency and semantic fidelity remain `unknown`/review findings.
- Semantic review is a separate, authorized proposal path. Fixture findings carry model/adapter/profile and evidence identifiers, but cannot mutate ontology, constraints, bindings, execution state, or human acceptance. Human decline is therefore retained as a review decision while technical outcome remains unchanged.
- `EvaluationReport` is a new layered projection compatible with the M5 `Evaluation` and `HumanAcceptance` records. Comparison ignores volatile timestamps and run identifiers but retains semantic hashes, versions, adapter/profile, budgets, destinations, and finding changes. Static HTML is deterministic, escaped, redacted, dependency-free, and never opens a browser.
- Provider response URLs and base64 are transient adapter inputs only. Successful persistence returns a safe `ArtifactHandle`; an unsaved URL or invalid output is an explicit persistence/validation failure. No production endpoint or request field is inferred beyond the generic envelope, and real smoke confirmation remains deferred.
