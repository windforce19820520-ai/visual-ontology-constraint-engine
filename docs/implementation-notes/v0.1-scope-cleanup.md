# v0.1 background-removal scope cleanup

- First-party virtual-try-on, cosplay, product-shot, and third-party fixtures now request complete opaque images.
- The concrete veImageX adapter, bundled background-removal step, transparent-cutout acceptance assertions, and related release-smoke language were removed.
- `OutputContract` may still describe image format and background requirements, and hosts may explicitly register a generic optional postprocessing step. Core does not bundle or select a background-removal service.
- Seedream remains the only concrete image-generation adapter planned for an optional credentialed smoke test. Standard development and CI remain offline.
- Removing the two concrete background-removal tests changes the standard suite floor from 105 to 103 tests; the release gate still requires zero failures and executes the same cross-platform safety coverage.
